# Cervinae_genomics

This repository contains the analysis scripts and command-line workflows associated with the manuscript:

> Shifting roles of incomplete lineage sorting and gene flow across the diversification of Old World deer
> Status: Preprint available at https://doi.org/10.64898/2026.11.24.768796

## Overview
In this study, we analyzed whole-genome resequencing data from 10 representative species spanning all six extant genera of Old World deer (subfamily Cervinae), using *Muntiacus reevesi* as the outgroup, to reconstruct their evolutionary history and partition the roles of incomplete lineage sorting (ILS) and historical introgression.
